v0.10.6 — Mobile safe-area emulation

Reflex 0.10.6 makes desktop mobile previews more representative of real devices. Bootstrap now uses full display dimensions and applies device-specific safe-area insets in portrait and landscape.

## Changes

- Update iPhone, iPad, Pixel, and Galaxy presets to preview how layouts fit around status bars, display cutouts, and navigation areas.
- Use the same client-inset handling for native mobile windows and desktop mobile emulation.
- Run Public SDK releases from a preparation branch. After public publication, CI squashes the licensed changes onto `dev`, tags the version, publishes the licensed release notes, and deletes the remote preparation branch.
