v0.3.0 — AUv3, CI pipeline and public SDK split

The first 0.3 release. Adds AUv3 support, builds the SDK through a proper CI pipeline, and separates what ships publicly from what stays internal: VST2 is excluded from the public repository and OpenGL is dropped from the macOS CMake configuration. Includes an SVG fill-rule correctness fix.

- AUv3: fix compile/API drift to build against current SDK
