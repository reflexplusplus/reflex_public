v0.10.0 — File handling and GLX alignment fixes

Reflex 0.10.0 improves large-file handling on POSIX and lets callers detect failed seeks. GLX centers fitted floating items within their margins, and `reflex version` reports when the repository and installed binaries are out of sync. See [Breaking Changes](../BREAKING_CHANGES.md#v0100) for API and release automation updates.

## Changes
### other
- Reuse build artifacts for public SDK verification
- Reflex CLI version reporting fix
- Fix POSIX file handles and report seek failures
- Return environment variable values as byte arrays
- Fix GLX float alignment
- Remove redundant source deletion after Windows rename
- Remove obsolete CloudStore declarations from table header
- Remove the legacy tag-triggered library and tool release workflow. Public releases use Release Public SDK.
- Rename the local licensed SDK exporter to `scripts/export_reflex_sdk.py`.
