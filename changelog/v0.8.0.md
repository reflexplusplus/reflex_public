v0.8.0 — MIDI-only Audio Units, secure random bytes, and runtime fixes

Changes in v0.8.0 since `v0.7.0` on the `edge` branch, covering 21 commits through `5c4501c4f` (2026-11-03).

This update adds host-side audio passthrough for MIDI-only Audio Units, cryptographically secure random-byte generation, CRC32C hashing, and binary-array property serialization. It also improves standard-stream handling and concurrent debug logging, adds configurable HTTP retries, and fixes GLX and resource-pool behavior.

## Changes

### Audio plugins

- Add stereo audio passthrough buses for macOS Audio Units whose class is an event processor or event generator with no audio outputs. This allows MIDI-only units to expose their editor in Logic while passing host audio through. The extra buses exist only in the Audio Unit host interface; the plugin's declared audio channels remain unchanged.
- Preserve passthrough audio independently of client input processing and host buffer lifetimes, and propagate input silence and render errors to the host.
- Correct Audio Unit factory/session ownership and instance allocation cleanup, and scope autorelease pools to factory, open, and close callbacks.

### Core and data

- Add `System::GenerateRandomBytes(ArrayRegion<UInt8>)` for synchronous cryptographically secure random-byte generation on Windows, macOS, iOS, Linux, Android, and web. It returns `true` when the whole region is filled; an empty region succeeds, and a failure leaves the contents unspecified.
- Fix web random generation with shared WebAssembly memory by generating into an unshared temporary buffer before copying into WASM memory.
- Add `Data::CRC32C` using the Castagnoli polynomial, including incremental hashing through the `previous` argument. Existing `Data::CRC32` behavior is preserved.
- Optimize `Data::SHA256` by processing complete input blocks directly instead of copying every byte through the internal buffer.
- Add `Data::ArrayOfBinaryProperty` (`ObjectOf<Array<Archive>>`) and serialization support for arrays of binary data in `Data::kPropertySetFormat`.
- Add `Reflex::Atomic<T>` as a generic alias for `std::atomic<T>`, retaining the existing named atomic aliases.
- Add `RemoveAdjacentDuplicates` to compact consecutive equal elements in an array, with an optional comparison policy.
- Fix bounds-checked `ReverseSplice` when the requested position exceeds the array size.
- Add UTF-8 support for supplementary Unicode characters, including UTF-16 surrogate-pair encoding and four-byte UTF-8 decoding.

### Standard streams and debug output

- Add `System::FileHandle::kStandardError` and its `kStandardStreamError` alias for wrapping standard error independently of standard output.
- Ensure standard-stream wrappers borrow their streams without closing them on destruction. On Windows, creating an output wrapper no longer seeks or truncates redirected output; stream flushing also handles terminals and pipes appropriately.
- Add web standard-output and standard-error wrappers that send UTF-8 text to browser host logging, flushing at newlines, explicit `Flush`, or destruction. Web standard input remains unavailable.
- Fix debug-output concurrency by using thread-local formatting scratch space and separate local buffers for log prefixes, assertions, and stack traces.
- Deprecate `Reflex::Detail::DebugJoin` in favor of `Reflex::Detail::FormatDebugOutput` with an explicit scratch buffer.
- Add `System::Detail::EmitClock()` for Windows, macOS, and Linux console builds, allowing console applications to dispatch one clock notification from the main thread.

### GLX and resources

- Add the default `&value` binding to the TextEdit layer.
- Fix `GLX::FlowDialog` content ownership and avoid emitting its page event before the dialog has an owner.
- Change `GLX::FlowDialog::GetCurrentPage()` to return the current page's `Key32` ID and make the method `const`.
- Fix out-of-bounds memory access in `File::ResourcePool::Lock::Clear` when no matching resources need removal.
- Remove an overly restrictive FreeType glyph-height assertion when rendering clipped glyphs.

### Async HTTP

- Add a trailing `UInt retry_count = 3` argument to `Async::Detail::CreateHttpRequest` and `Async::Detail::Fetch`, allowing callers of these detail APIs to configure the retry budget. Existing calls and the public convenience overload retain the default of three retries.

### CLI, builds, and distribution

- Fix SDK-root detection for bootstrap CLI installations that do not yet contain SDK headers, including the macOS website installation flow. If the installation root cannot be determined, `reflex install` now reports an explicit error directing the user to pass `--path <folder>`.
- Strip local and debugging symbols from macOS Release builds of ReflexCLI before signing and installation, in both its cfg and checked-in CMake build. Debug builds retain symbols.
- Support signing macOS CLI Release builds with `REFLEX_CODESIGN_IDENTITY`, hardened runtime, a timestamp, and signature verification; retain ad-hoc signing when no identity is configured.
- Document ordered macOS stripping and signing steps in [the build guide](../documentation/reflex-build.md#stripping-macos-release-symbols).
- Make the plugin test project's VST2 target conditional on `VST2API_PATH`.
- Keep macOS CI on system Python without the minimum-version check or `setup-python` fallback.
- Update public export rules to exclude Linux `ReflexSystemVST2` Debug and Release libraries.

## Compatibility notes

- `GLX::FlowDialog::GetCurrentPage()` now returns a `Key32` page ID instead of the page content object. Update callers that used its previous object return value.
- New binary-array properties require a reader with the corresponding `kPropertySetFormat` support. Consider older-reader compatibility before writing these properties to shared or persistent data.
- Code using the internal `DebugJoin` helper should migrate to `FormatDebugOutput` and supply its own scratch buffer.
