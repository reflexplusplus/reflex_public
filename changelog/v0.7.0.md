v0.7.0 — Viewport improvements, audio-plugin updates, and Linux desktop integration

Reflex 0.7.0 improves viewport layout and scrolling, adds stylesheet-configurable scrollbar positioning and independent bar toggles, and updates audio-plugin host detection, CLAP event access, and VST2 integration. Linux gains application icons, desktop launchers, Debian/Ubuntu packaging, and experimental status items. CMake and CLI updates improve AAX SDK integration and project generation, with target-specific builds and command-local variable overrides. The release also improves VM execution and bindings, fixes core and async behavior, and adds prebuilt WebAssembly libraries. Several APIs and build settings require migration from v0.6.0; see [Breaking Changes](../../BREAKING_CHANGES.md#v070).

## Changes

### GLX

- Allow viewport scrollbar positioning to be configured in stylesheet `x` and `y` blocks, for example `x: { positioning: float; };`, and support the new `float | float` positioning mode.
- Allow viewport bars to be toggled on and off independently of their constructors through `EnableViewBars`.
- Fix viewport layout, scrolling, synchronization, grid updates, and RangeBar behavior.
- Allow `Bootstrap::GenericControl` styling delegates to receive `OnSetStyle` and remove inappropriate constness from generic drawing layers.

### Audio plugins

- Add `System::AudioPlugin::GetHostName()`, which reports the host of each plug-in instance, so that two hosts in one process (for example, Max for Live inside Ableton Live) each get the correct name. `AudioPlugin::GetPluginHost()` is removed.
- Add the experimental `System::ClapEventsProperty` extension for access to raw CLAP events.
- Increase the VST2 output event buffer to 256 events and retain the latest events in order on overflow; reserve output event storage during construction.
- Correct the VST2 parameter-properties opcode and add missing plugin-category values.

### Linux improvements

- Add Linux desktop integration for app targets with an `icon` setting: generated Make and CMake builds stage the executable, desktop launcher, and icons under `package/usr/`. Stock app templates include Linux icons and a `package_id`. Regenerate existing projects to enable the generated packaging files.
- Set Linux X11 window classes from the executable name so desktop environments can associate application windows with their generated launchers and icons.
- Generate `package-deb.sh` beside Linux app executables to create Debian/Ubuntu packages, with configurable package metadata and automatic linked-library dependency detection. Run `sh package-deb.sh` in the output directory after building; packaging requires a maintainer value, `dpkg-dev`, and `binutils` on a host matching the executable's architecture. See [Linux application packaging](../../build/tools/ReflexCLI/resources/project_generator/linux-packaging.md) for settings and requirements.
- Add Linux support for the experimental `System::StatusItem` API.

### Platform and process support

- Add independent standard-error redirection through `System::Process::Options::std_err`, and include child-process errors in CLI command output.
- Remove the deprecated `System::Process::Detach()` API and change the Windows `allow_window` default to `true` for console inheritance.
- Restore the default macOS library deployment target from 12.0 to 10.15.

### CMake

- Building the `AAX` format with `reflex_add_audio_plugin` now requires a separately installed Avid AAX SDK, version 2.9 or later. Set `AAX_SDK_PATH` as a CMake cache variable or an environment variable pointing to the SDK root. The prebuilt `ReflexTargetAAX` library contains only the Reflex AAX integration code. CMake builds the SDK once using its supplied CMake project, and each AAX plugin links against it. On macOS, the SDK project enables `OBJCXX`, so Makefile and Ninja projects that compile their own `.mm` files must enable it too. Configuration fails if `AAX_SDK_PATH` is missing or invalid, or if the SDK is older than 2.9. It issues a warning for a newer version, as only 2.9 has been tested, or if the SDK version cannot be read. If you build Reflex from a source checkout, rebuild `ReflexTargetAAX`. This is a breaking change for AAX builds.
- Give generated macOS AAX bundles `PkgInfo` and a `Resources` directory so PACE wraptool recognizes their bundle layout.

### ReflexCLI and project generation

- The `cpp_audioplugin_aax` template compiles the Avid library sources from the SDK location configured with `reflex set AAX_SDK_PATH <path>`.
- Add `reflex build --target <name>` and generate VS Code build tasks and debug launches for individual targets.
- Add command-local `--variables <PropertySheet>` overrides for project creation, generation, building, cleaning, and editing, with precedence over persistent variables.
- Move the framework build description to the root `project.cfg` and add `package.cfg` for library-only consumers using source or prebuilt dependencies.
- Make stock VST2 cfg targets and templates conditional on `VST2API_PATH`.
- Allow nested `generated_directory` paths inside the project and keep that setting local to the root document.
- Fix Xcode project generation and a CLI project-schema memory leak; expose `OutputDirectory` and `Entitlements` to build steps and add optional macOS release signing through `REFLEX_CODESIGN_IDENTITY`.
- Generate VS Code configuration automatically with other outputs; remove `vscode` as a standalone generation output.

### VM

- Improve object-temporary optimization, forwarding, slot coalescing, and ownership transfer, along with context setup, cleanup, and operand-stack capacity checks.
- Change switch handlers to colon-based `case` and `default` labels and accept negative numeric constant literals.
- Replace the built-in `reinterpret<T>` operation with explicitly registered conversions through `VM::BindReinterpret`.
- Extend queues to value types up to 32 bytes, fix reader/writer ownership and access handling, and use the explicit `Pop(destination)` API.
- Fix cross-context PropertySet access, array buffer capacity handling, and `ObjectOf<T>` serialization registration; support boolean string formatting and printing.
- Add an object-class constraint to `BindObjectMethod`, improve global registration diagnostics, and update external drag-and-drop translation to the GLX API.

### Core, files, and async

- Add `Async::IsAwaiting` and remove completed await registrations before callbacks, allowing callbacks to attach a replacement await safely.
- Fix normalization of dot segments in `File::ResolveRelativePath` and `ResolveIncludePath`, preserving trailing folder strokes.
- Provide automatic null instances for `Allocation<T>` of trivial types.

### Distribution and build verification

- Publish prebuilt WebAssembly libraries and add web build verification in CI.
- Add manually selectable build checks, optional template builds, and CLI variable overrides to the build-check workflow.
- Improve Linux compiler-warning handling and add a local public-export script.
