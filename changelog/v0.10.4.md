v0.10.4 — GLX fixes and explicit Web arguments

Reflex 0.10.4 fixes nested menu root tracking and a memory leak when stylesheet inheritance fails to parse. Linux console targets now include shared graphics helpers, and Web launchers can pass application arguments explicitly through the `commandLine` option to `startReflex()`. Apps that relied on automatic URL query forwarding need to update their launcher. See [Breaking Changes](../BREAKING_CHANGES.md#v0104).

## Changes
### other
- GLX::Menu fix
- web replaced builtin query to cmdline with explicit commandLine arg
- GLX fix leak on inherit parse error
- Include shared graphics helpers in Linux console targets
