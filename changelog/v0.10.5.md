v0.10.5 — Explicit string decoding and VM hashing

Reflex 0.10.5 removes the previously deprecated generic `WString` deserializer in favor of explicit string encodings. The VM compiler also updates its argument-signature hashing. See [Breaking Changes](../BREAKING_CHANGES.md#v0105) to migrate any remaining legacy string deserialization.

## Changes

- Remove the deprecated `Data::Deserialize<WString>` and add `Data::Detail::WStringUCS2` for explicitly encoded strings in generic serialization.
- Update VM compiler argument-signature hashing.
