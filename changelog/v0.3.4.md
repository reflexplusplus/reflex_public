v0.3.4 — plugin version reporting across formats

Plugin versions now come from a single PRODUCT_VERSION rather than being hardcoded per format. CMake drives Info.plist and run-time version from it, and VST2 reports a version matching JUCE's encoding so hosts read it correctly. Adds ReflexCLI build-plist.

## Changes
### CMake
- CMake: drive Info.plist + run-time version from PRODUCT_VERSION
- CMake: thread real version into app/standalone Info.plist
- CMake: name app binary after NAME to match CFBundleExecutable
- CMake: build ObjC++ entry sources with MRC, not ARC
- cmake: normalize plugin source paths to forward slashes (fix Windows configure)

### ReflexCLI
- ReflexCLI: added missing iOS plist to build-plist & distinguish app & audioapp
- ReflexCLI: add CFBundleShortVersionString to macOS app/audioapp plists
- ReflexCLI: all plist names lowercase for consistency

### VST2
- VST2: report version from cls.version instead of hardcoded constants
- VST2: match JUCE's version encoding for effGetVendorVersion
