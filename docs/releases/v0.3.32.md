v0.3.32 — unified builds and configurable formats

Reflex Build now provides a more complete project-generation workflow, including CMake output, persistent variables, reusable tasks, and generated schema validation. Data formats now accept structured `PropertySet` options, allowing PropertySheet conditionals and other format behaviour to be configured without fixed bit flags. This release also improves Android navigation and keyboard handling, licensed source builds, GLX text transforms, Windows compatibility, and application templates.

## Changes

### Reflex Build and project generation

- Expanded `reflex generate` into the unified Reflex Build workflow for Visual Studio, Xcode, Android, Linux Makefiles, and CMake.
- Added generated project-schema revisions and stronger validation for `project.cfg` structure, inheritance, platforms, targets, configurations, dependencies, and build actions.
- Added persistent build variables with `set`, `get`, `unset`, and `variables` commands, including support in conditional preprocessing, include paths, and project-variable expansion.
- Added import and export of persistent variables and saved tasks through PropertySheet configuration files.
- Added reusable named tasks that can chain generation, build, run, and other commands with task-specific inputs.
- Added convenience commands for cleaning, building, running, and opening generated projects.
- Added CMake generation as a first-class emitter driven by the same `project.cfg` source as native projects.
- Reworked the shared SDK project configurations, templates, examples, tools, and build matrix around the revised schema.
- Consolidated project-generation documentation into the new Reflex Build guide.

### Data formats and PropertySheet

- Replaced numeric format flags with structured `PropertySet` options across format encoding, decoding, serialization, and deserialization APIs.
- Moved PropertySheet conditional evaluation into format options so callers can supply configuration without mutable format-global state.
- Refactored PropertySheet conditional parsing and callback context handling.
- Renamed the custom PropertySheet format factory to `CreatePropertySetFormat` and updated its interface lifecycle and callback signatures.

### Android input and navigation

- Android system back actions now produce Escape-key navigation consistently across older and newer Android versions.
- Flow dialogs now handle Escape by returning to the previous page.
- Prevented duplicate key handling while the Android virtual keyboard is active.
- Fixed hidden text input controls taking focus unexpectedly.

### Distribution and platform fixes

- Licensed source releases now include host tool archives and fetch tools from the licensed repository when building the framework from source.
- Fixed Reflex download logic to distinguish host tools from target-platform libraries.
- Fixed Windows macro definitions for the conforming MSVC preprocessor.
- Updated Android application templates with splash-screen assets and refreshed platform configuration defaults.

### GLX and UI

- Replaced the text `initial` transform with `initials`, which produces initials from every word rather than taking only the first character.
- Simplified GLX text transformation and scratch-buffer handling.

### Migration notes

- Calls to `Format::Encode`, `Format::Decode`, `SerializableFormat::Serialize`, `SerializableFormat::Deserialize`, and their helper functions must replace numeric option flags with a `PropertySet` when options are required.
- Custom PropertySheet format implementations must adopt the new context-aware interface callbacks and use `CreatePropertySetFormat`.
- Stylesheets using `transform: initial` must change to `transform: initials` and should account for its new multi-word behaviour.
- Projects using generated build files should regenerate them with the updated ReflexCLI and review the revised `project.cfg` schema and variable handling.
