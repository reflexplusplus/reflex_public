v0.3.15 — per-key note names across all plugin formats

Plugins can report instrument-specific note names through OnGetNoteName and ReportNoteNamesChanged, surfaced natively by CLAP, VST2 and VST3. Also fixes parameter state being read from the descriptor array rather than the saved chunk, and orders the new virtuals last to keep the vtable ABI stable.
