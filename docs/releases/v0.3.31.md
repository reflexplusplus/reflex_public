v0.3.31 — generated projects and multi-class plugins

Reflex projects can now generate their native build files from a shared `project.cfg`, replacing the hand-maintained platform projects previously shipped with templates and examples. This release also enables multi-class audio plug-in binaries, expands MIDI and Linux support, and improves ownership diagnostics, cross-platform builds, and plug-in host integration. Several API changes require migration when updating existing audio plug-ins or direct `System::Window::Client` implementations.

## Changes

### Project generation and tooling

- Added `reflex generate` for generating Visual Studio, Xcode, Android/Gradle, and Linux projects from an inheritable `project.cfg`.
- Added scoped project configuration for platforms, targets, configurations, variables, and build actions.
- Migrated SDK libraries, templates, examples, tools, and test projects away from hand-maintained native project files.
- Generated project and resource outputs are no longer generally tracked in source control.
- Added `~` home-directory expansion to ReflexCLI.
- Improved `reflex doc` error reporting and fixed a related memory leak.
- ResourceBuilder now includes extensionless files.

### Audio plug-ins

- Added support for multiple plug-in classes in one Bootstrap binary, including shell plug-ins and multi-component AUv2 and AUv3 bundles.
- Added MIDI output support to the AUv2 wrapper.
- Added standalone MIDI output on macOS through CoreMIDI.
- Connected AUv3 host transport state to the real-time event clock.
- Added VST3 bus-count validation and fixed-stereo arrangement handling.
- Fixed an audio event-queue wraparound overflow.
- Improved embedded macOS plug-in editor positioning and resizing.
- Added a resize workaround for AUv2 editors.
- Fixed Bootstrap parameter controls consuming unrelated events.

### Platform and build support

- Implemented `System::Process` on Linux.
- Added `System::GetPath(kPathUserHome)`.
- Improved Android keyboard Enter handling, build warnings, resource integration, and background audio-service behaviour.
- Fixed iOS cross-compilation dependency discovery and host/target selection when downloading SDK tools and documentation.
- Added automatic post-build signing for macOS bundles, with options to disable signing or select a signing identity.
- Fixed minimal macOS System-only builds and macOS process-output synchronization.
- Removed the obsolete monolithic CMake `reflex` target and expanded distribution-consumer validation.

### Core API and diagnostics

- Added `[[nodiscard]]` diagnostics to `New` and other ownership-sensitive factory and acquisition APIs.
- Hardened `ArrayView` construction and assignment against unsafe conversions.
- Added a default constructor to `Signal::Listener`.
- Added policy support to `FieldCompare`.
- Added `System::Window::GetRect()` and `GetDisplayMode()`.
- Reworked window-client attachment into explicit attach and detach lifecycle callbacks.
- Renamed `File::CorrectExtension` to `File::SetExtension`; the old name remains available but deprecated.
- Deprecated `System::Process::Detach`.
- Changed `Data::GetError` to return an `Optional`, making the absence of an error explicit.

### GLX and UI fixes

- Gesture recognizers now focus the accepted gesture target and retain gesture state safely across callbacks that may destroy UI objects.
- Fixed responsive size deduction for styled text and images.
- Fixed rotary controls failing to delegate unhandled keyboard input.
- Improved macOS captured-resize behaviour by preventing recursive mouse-event re-entry.
- Improved embedded plug-in window attachment and presentation handling.
- Cleaned up several Clang, Xcode, Android, and pedantic compiler warnings.

### Migration notes

- Bootstrap audio plug-ins must replace `MakeClass()` with `MakeClasses()`, accept the selected `Class` in `Create(...)`, and pass that class to the `Bootstrap::AudioPlugin` instance constructor.
- Audio Unit configuration must replace `AU_TYPE_4CC` and `AU_UID_4CC` with one or more comma-separated `AU_COMPONENTS` entries. Previously published CLAP, VST, and Audio Unit identifiers must remain unchanged.
- Projects should add or update `project.cfg`, then regenerate their native projects with `reflex generate --path <project.cfg>`.
- Direct implementations of `System::Window::Client` must adopt `OnAttachWindow` and `OnDetachWindow`.
- Callers of `Data::GetError` must handle its new `Optional` result.
